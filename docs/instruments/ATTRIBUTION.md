# Instrument asset provenance

Chain Dials draws every instrument from code. There are no sourced meshes,
photographs or scanned materials. This file exists so that stays true on
purpose: anything added later gets a row here first.

Rules, from the playbook:

- Prefer CC0 with recorded author, URL, licence, date and sha256.
- Check size and polygon count before fetching anything.
- Treat sourced assets as evaluation assets until they pass review on the harness.
- Development geometry is labelled as such in the UI and in docs.
